### 3.1 测试期间发现并修复的缺陷（D7 相关）

- **现象**：后端不可用时，历史页仅弹出瞬期 toast，表格显示"Total 0/暂无识别记录"，
  用户可能误判为"没有历史记录"。
- **修复**：`frontend/src/views/HistoryView.vue` 增加持久错误提示（`el-alert`），
  空状态文案在加载失败时显示"加载失败，请重试"。
- **验证**：修复后实测（D7）显示"无法连接后端服务，请确认服务已启动" + "加载失败，请重试"；
  Vitest 18/18 与生产构建复跑通过。

## 四、统计耗时差异专项核查（921.32ms vs 稳态数毫秒）

**结论：差异真实存在且可完全解释，统计接口计算正确，无需修改代码或数据。**

正式数据库 3 条记录的真实 `inference_ms`（2026-10-14 实测）：

| 记录 | 场景 | inference_ms |
|---|---|---|
| id=1（beagle） | 阶段 4 首次请求（含 CUDA 初始化） | 1441.223 |
| id=2（Siamese） | 阶段 5 首次请求（含 CUDA 初始化） | 1316.917 |
| id=3（Siamese） | 稳态请求 | 5.805 |
| **平均** | | **921.32** |

- 后端 `GET /api/stats` 对全部记录求平均（`func.avg`），计算无误；
- 冷启动原因：GPU 首次前向包含 CUDA context 初始化、cuDNN autotuning 与首次内核编译，
  发生在每个服务进程的第一次推理（阶段 3 benchmark 已用 10 batch 预热排除该影响，
  测得稳态单张 2.95ms / batch 吞吐 1184.9 img/s）；
- 本轮实测稳态：D2 识别 inference≈5ms、临时环境 C2 为 218ms（服务刚启动的首次请求）、
  C13 之后的稳态预测约 5ms；
- **口径区分**：数据库 `avg_inference_ms` 是"全部历史记录（含冷启动）的平均"；
  单次稳态推理约 2.95–5.8ms；两者不可互比。README 与 API 文档均已注明三种计时口径。
