# U6 / V2.2：边境牧羊犬准确率专项改进计划

> **状态**：计划阶段。**本阶段（U5.5）不训练 V2.2、不改数据、不改标签。**
> **前置**：V2.1（136 类）已于 U5.5 接入为默认模型，四类候选组 B1 默认开启。
> **基线模型（冻结）**：`artifacts/v2_1_136classes_seed42/best_model.pth`
> **生成时间**：2026-10-19

---

## 0. 一句话目标

在**不显著伤害其他类别**的前提下，提升 `collie`（柯利牧羊犬）与
`border_collie`（边境牧羊犬）的区分能力。

---

## 1. 已知起点（全部为"待验证线索"，**不是因果结论**）

| # | 已知事实 | 证据来源 | 性质 |
|---|---|---|---|
| 1 | `collie` 与 `border_collie` 的错误存在**毛色关联迹象**，黑白色柯利更易被判为边牧 | `reports/v2_1_coat_pitbull_diagnostics/` | 相关性，非因果 |
| 2 | 全 split `collie → border_collie` 共 **17 张**（train 5 / val 4 / test 8） | `collie_to_border_collie_cases.csv` | 直接计数 |
| 3 | 这 17 张中仅 5 张可自动判为黑白、2 张陨石、1 张三色，**9 张毛色待复核** | 同上 | 说明毛色只能解释一部分 |
| 4 | 自动 HSV 毛色启发式 **56.2% 为 uncertain**（167/297） | `coat_color_distribution.csv` | **不可当作可信真值** |
| 5 | 人工复核队列按"误判或毛色待复核"选样，**存在选择偏差** | `coat_color_review_queue.csv` 183 行 | 不可外推为全量准确率 |
| 6 | V2.1 test 上 `collie` F1 ≈ **0.5517**（16 张）、`border_collie` F1 ≈ **0.6316**（15 张） | `classification_report.csv` | **样本极少，数字不稳定**，仅作基线 |
| 7 | 训练集毛色分布两类不同：`collie` 貂色 15/121、红白 9/121；`border_collie` 两者均 0 | `coat_color_distribution.csv`（train） | 分布事实 |
| 8 | 混杂因素效应量全部 < 0.25（尺寸/宽高比 0.000、亮度 0.134、背景 0.144） | `coat_confounders.csv` | **未发现系统性裁剪/背景差异** |
| 9 | 两类**同源**（Stanford Dogs `n02106030` / `n02106166`） | 文件名 wnid | 可排除"来源不同"作为解释 |

**重要提醒**：第 6 项的两个 F1 是**仅 16/15 张测试样本**上的数字，
按二项分布估算 95% 置信区间宽度可达 ±0.2 以上。**不得用 test 反复调参**。

## 2. 执行原则（硬性）

1. **冻结基线**：V2.1 checkpoint、`class_names.json`、`experiment_config.json`
   在本阶段只读，实验产物一律写入新的版本化目录。
2. **只用 train/val 设计与比较**；test 仅在**选定最终候选后评估一次**。
3. **不改标签**：任何重新标注/移动图片必须先产出独立清单，等人工批准后才执行。
4. **一次只改少量因素**，避免无法归因。
5. **同时报告全量指标**，不允许"只优化边牧、牺牲其他类"。

---

## 3. 分阶段任务

### 阶段 U6-A：建立可信基线（预计 0.5 天）

| 任务 | 产出 | 完成判据 |
|---|---|---|
| 冻结 V2.1 并记录 SHA256 | `u6_baseline.json` | 哈希与 U5.5 记录一致 |
| 在 **val** 上重算 `collie` / `border_collie` 的 P/R/F1 与双向混淆 | `u6_baseline_val.csv` | 有明确分母（val：`collie` 16、`border_collie` 15） |
| 明确"改善"的可量化判据 | 见第 5 节 | 阈值在实验前写定 |
| 记录 test 基线（**只看一次，不据此调参**） | `u6_baseline_test.csv` | 与 V2.1 报告数字一致 |

> **注意**：val 每类仅 15–16 张，验证集本身也很小。若要在 val 上做可信比较，
> 需要考虑**多次随机种子/交叉验证**或多指标联合判断，避免被单次波动误导。

### 阶段 U6-B：数据分布审计（预计 1 天）

| 任务 | 产出 |
|---|---|
| 按 train/val/test 分别盘点两类的**人工可确认毛色**分布（只用人工复核过且明确的样本，uncertain 单列） | `u6_coat_distribution_by_split.csv` |
| 盘点**照片来源/构图/背景/尺寸**（复用 U5 的混杂因素脚本） | `u6_confounders_by_split.csv` |
| 统计两类在 train 中的样本量差异（121 vs 114）与新增类的分布 | `u6_sample_counts.csv` |

**约束**：test 只做**最终描述性统计**，不用于挑选训练策略。

### 阶段 U6-C：人工复核数据整理（预计 0.5 天）

| 任务 | 产出 |
|---|---|
| **只读**解析 `coat_color_review_queue.csv` 的 `review_notes` 自由文本，保留原文 | `u6_manual_review_parsed.csv` |
| 无法明确确认的标为 `uncertain`（**不猜**） | 同上 |
| 如需重新标注/移动标签 → 先输出 `u6_relabel_proposal.csv` 等人工批准 | 独立清单 |
| **禁止自动重标** | — |

### 阶段 U6-D：候选实验设计（预计 2–3 天，逐实验）

| 实验 | 变量 | 预期作用 | 风险 |
|---|---|---|---|
| `exp01` | 颜色扰动增强（亮度/饱和度/色调抖动） | 降低对毛色的依赖 | 可能伤害本身依赖毛色区分的类（如陨石色边牧） |
| `exp02` | `collie` / `border_collie` 加权采样或类别权重 | 缓解样本量/难度不均 | 可能过拟合少数类 |
| `exp03` | 针对两类的定向增强（随机裁剪比例、翻转、遮挡） | 提升泛化 | 对整体影响不确定 |
| `exp04` | 仅在两类上做小学习率微调（其余类冻结） | 精准改善 | 破坏 136 类整体校准的风险 |
| `exp05` | 提高输入分辨率（224→256/288）作为对照 | 捕捉更细的形态差异 | 推理成本上升 |

**每次只启一个实验**，独立目录：`artifacts/v2_2_border_collie_exp01/` …
**不覆盖** V2.1 / V1.1 / 当前正式模型。

### 阶段 U6-E：评估与决策（预计 0.5 天）

每个候选必须同时报告：

1. **136 类整体 Macro-F1**（val）
2. **原 37 类子集** Macro-F1
3. `collie` 与 `border_collie` 的 P/R/F1（val）
4. 两类**双向混淆率**
5. 其他新增犬种中**是否有明显退化**
6. 样本量与置信区间/小样本限制说明

**只有同时满足第 5 节判据的候选**才进入 test 一次性评估。

---

## 4. 防止过拟合测试集

| 措施 | 说明 |
|---|---|
| 模型与超参由 train/val 决定 | test 只在最终候选确定后跑一次 |
| 记录"test 访问次数" | 每次访问写入实验日志，便于审计 |
| 报告样本量 | 每类 15–16 张必须显著标注 |
| 报告不确定性 | 给出 Wilson/自助法置信区间，避免把 0.05 的波动当改进 |
| 不做"看 test 再改一版" | 若需第二轮，必须重新划分或等待新的独立测试集 |

---

## 5. 成功标准（**须在实验开始前确定，不得看到 test 结果后修改**）

建议在 U6-A 阶段用 **val** 基线确定以下阈值：

| 指标 | 建议判据（待 U6-A 用 val 确认） |
|---|---|
| `collie` F1（val） | 提升 ≥ **+0.10** 绝对值 |
| `border_collie` F1（val） | 不低于基线 −0.02 |
| 两类双向混淆率（val） | 相对下降 ≥ **30%** |
| 136 类整体 Macro-F1（val） | 退化 ≤ **预设容忍值**（建议 **−0.01**） |
| 原 37 类子集 Macro-F1（val） | 退化 ≤ **0.005** |

> 上述数值为**建议初值**，必须在 U6-A 看到 val 基线后**正式写定并冻结**，
> 之后任何一轮都不得修改判据。

## 8. 风险与未知

1. **样本量太小**：val 每类 15–16 张、test 16/15 张，任何"改进"都可能是噪声。
2. **毛色标签不可靠**：56.2% uncertain，无法用毛色做严格的因果分层。
3. **两类可能本质相近**：若人工复核确认存在"同犬不同标"，则应优先修数据而非调模型。
4. **改动可能伤害其他类**：136 类中不少犬种与柯利/边牧形态相近（如喜乐蒂牧羊犬）。
5. **本计划不包含重新标注**：任何标签变更都需人工逐条批准。
