## 1. 任务目标

基于已经训练完成的 V2.1 候选模型，生成一份可复核的 **V2.1 误分类诊断报告**，重点回答：

1. V2.1 为什么在 APBT（`american_pit_bull_terrier`）上的 Recall 仅为 0.14？
2. APBT 被预测为 AmStaff（`american_staffordshire_terrier`）、Staffordshire Bull Terrier、American Bulldog、Bullmastiff 等类别，主要呈现什么模式？
3. 误分类是否可能与**标签噪声、数据来源差异、同类犬外观相似、类别样本量/划分特点、图片重复或近重复**有关？哪些结论有证据，哪些只是待验证假设？
4. V2.1 扩展到 136 类后，对原有 37 类图片产生了哪些新增误判？特别是原有 37 类被预测成 99 个新增犬种的情况。
5. 哪些样本值得人工复核，以及是否有值得进一步审核的外部数据源？本任务仅做审计，不下载或合并新数据。

## 5. 误分类诊断内容

### 5.1 全部 136 类和原有 37 类影响

至少输出：

- 全部 136 类的分类报告（Precision / Recall / F1 / support）及 Macro-F1、Weighted-F1、Accuracy。
- 完整混淆矩阵 CSV；另提供易读的可视化版本。
- 原有 37 类测试样本的逐图预测结果，并按下列情况分桶：
  1. 预测正确；
  2. 误判为另一个原有类别；
  3. **误判为新增 99 类中的某一类**。
- 对第 3 桶统计数量、比例、真实类别、最常见的误判目标；生成 CSV，供后续人工核查。
- 在完全相同的 3,669 张原有测试图片上，分别记录 V1.1 与 V2.1 是否预测正确。不要把不同类别空间下的 raw softmax 概率当作可直接比较的置信度。
- 如果 V1.1 和 V2.1 图片顺序不同，必须通过稳定的相对路径/样本 ID 一一匹配，禁止按 DataLoader 顺序假定对应关系。

### 5.2 APBT / AmStaff 专项

针对真实标签为以下类别的测试图片逐张生成预测清单：

- `american_pit_bull_terrier`
- `american_staffordshire_terrier`
- `staffordshire_bull_terrier`
- `american_bulldog`
- `bull_mastiff`（以实际 canonical label 为准；先核实名称，不要自行改类名）

每张图片至少记录：

- split、真实 canonical label、图片相对路径、图片文件名、来源标识（若可从目录/文件名/manifest 确认）、宽高；
- top-1 预测、top-1 概率、top-5 预测及概率；
- APBT 与 AmStaff 各自的概率/排名（如能从模型 logits 可靠获取）；
- 是否预测正确、错误目标类别。

至少分别统计：

- APBT 的 top-1 混淆去向与数量/比例；
- AmStaff 的 top-1 混淆去向与数量/比例；
- APBT 与 AmStaff 的双向混淆率；
- APBT 被预测为 Staffordshire Bull Terrier、American Bulldog、Bullmastiff 的数量/比例；
- 以上类别预测置信度分布，以及低置信度、相近 top-1/top-2 分数的样本数量。

不要仅凭置信度高就判定标签正确，也不要把低置信度等同于标签错误。

### 5.3 Border Collie / Collie 专项

对 `border_collie`、`collie`、`border_terrier` 生成同样的逐图清单与混淆统计。明确标注每类测试支持数，避免因测试样本少而夸大结论。特别核查真实 `collie` 被预测为 `border_collie` 的样本，但不得因此合并类别。

### 5.4 APBT / AmStaff 标签与图片重复审计

只读检查以下类别之间的图片关系：

- `american_pit_bull_terrier`、`american_staffordshire_terrier`、`staffordshire_bull_terrier`、`american_bulldog`、`bull_mastiff`（使用真实 canonical label）。

检查范围：

1. 相同 split 内跨类别 MD5 完全重复；
2. 相同 split 内跨类别 pHash 近重复，阈值沿用项目已有定义（汉明距离 ≤ 5）；
3. 跨 split 是否存在任何相同图或近重复图；
4. 若有可用的来源 manifest 或原始文件路径，统计各类别来源分布。

输出每个可疑匹配对的两端类别、路径、split、MD5、pHash 距离和图片联系表。**不要自动删除重复对，也不要自动决定哪个标签正确。** 若既有 `verify_v2_dataset.py` 已覆盖某些检查，应引用该结果并补充它未覆盖的“同一 split 跨类别”检查。

### 5.5 人工复核材料

生成一份可人工审核的 `reports\v2_1_diagnostics\manual_review_queue.csv`，按优先级列出：

1. APBT ↔ AmStaff 双向互相误判；
2. APBT ↔ Staffordshire Bull Terrier / American Bulldog / Bullmastiff 的混淆；
3. APBT / AmStaff 之间或相关类别间的跨类别 MD5 / pHash 可疑匹配；
4. 原有 37 类被预测为新增类别的样本；
5. `collie` ↔ `border_collie` 互相混淆样本。

字段至少包括 `priority`、`true_label`、`pred_label`、`top1_prob`、`top5`、`split`、`image_path`、`source_evidence`、`review_status`、`review_notes`。`review_status` 初始留空，不自动打上“错标”结论。

若生成联系表图片，每张图必须显示样本 ID、真实标签和预测标签；只复制/缩放到报告输出目录，不可改写原始图片。

## 6. 数据源可信度与外部候选数据源初筛

在诊断报告内单独写一个**证据等级明确**的小节，回答“目前数据是否可能把 APBT 与 AmStaff 标签混在一起”以及“新增数据能否解决问题”。

要求：

2. 检查现有 manifest、类别目录、文件名、来源信息和原始标签；记录可证实的事实与无法确认的事项。
3. 对公开候选数据源只做元数据/许可/来源初筛，不下载、不解包、不合并任何新图片。至少检查：
   - `images.cv` 上 APBT 与 AmStaff 的分类图片集合（搜索页面分别报告约 123 张 APBT、约 1.3K 张 AmStaff，并显示来源为 ImageNet object localization；必须核实当前页面和具体许可，不能把网页宣传当作标签质量证明）；
   - 是否存在明确说明纯种身份/犬舍/犬展登记来源、标签可追溯、许可清晰的 APBT 与 AmStaff 数据。
4. 对每个候选源填写：URL、标签定义、图片数量、原始来源、是否可能与 ImageNet/Stanford Dogs 重叠、许可证和使用限制、能否追溯每张照片标签、初筛结论（候选/暂不采用/需授权）。
5. **不能仅因为图片数量多就推荐使用。** 若找不到具备可靠独立标签和明确许可的公开数据集，明确说明“本轮未找到经验证更可靠的公开替代源”，不要伪造一个已确认可用的数据集。
