## 7. 边境牧羊犬准确率改进：明确排入下一阶段 U6/V2.2

**边牧准确率必须成为下一阶段的重点，但不能阻塞 V2.1 先接入。** 本阶段只形成可执行的专项计划，不训练 V2.2、不改数据、不修改标签。

### 已知问题（作为诊断起点，不可直接当因果结论）

- 先前诊断发现 `collie` 与 `border_collie` 的错误存在毛色关联迹象，尤其黑白色柯利牧羊犬更容易被预测为边境牧羊犬。
- 用户已经人工审核 `coat_color_review_queue.csv` 中的备注；该队列按“误判或自动毛色待复核”选样，存在选择偏差，不可直接当作全量数据的无偏准确率。
- 自动 HSV 毛色估计约 56.2% 样本为 uncertain，不能把自动毛色标签当作可信的人工真值。
- 当前 V2.1 test 报告中 `collie` F1 约 0.5517、`border_collie` F1 约 0.6316；每类测试样本数较少（16 / 15），数字不稳定，作为基线记录，不可用 test 反复调参。

### U6/V2.2 专项任务计划至少包含

1. **建立可信基线**：冻结 V2.1 checkpoint 与配置；仅用 train/val 设计和比较改动，保留测试集一次性最终评估原则。
2. **数据分布审计**：按 train/val/test 分别盘点 `collie` 与 `border_collie` 的人工可确认毛色分布、照片来源/构图/背景、图像数量。测试集只做最终描述性统计，不用于挑选训练策略。
3. **人工复核数据整理**：将已有自由文本 `review_notes` 只读解析并保留原文；无法明确确认的标注为 uncertain；如需重新标注/移动标签，必须先输出独立清单等待用户人工批准，禁止自动重标。
4. **预先定义候选实验**：例如适度颜色扰动、采样/类别权重、训练分布平衡或有针对性的增强；一次只改变少量因素，优先用 validation 的 `collie` / `border_collie` F1、两类混淆率及 136 类整体 Macro-F1 选策略。
5. **保护其他类别表现**：任何候选模型都必须同时报告 136 类整体 Macro-F1、原 37 类子集、`collie`、`border_collie` 和其他新增犬种表现；不能只优化边牧指标而明显伤害其他类。
6. **独立输出**：V2.2 所有实验写入新的版本化目录（例如 `artifacts\v2_2_border_collie_exp01\`），不覆盖 V2.1、V1.1 或当前正式模型。
7. **防止过拟合测试集**：模型和参数由 train/val 确定；test 只在选定最终候选后评估一次。报告同时呈现样本量、置信区间或小样本限制。
8. **成功标准先写在实验前**：提高 `collie` 与 `border_collie` 区分能力，同时要求整体 136 类 Macro-F1 不出现超过预设容忍值的退化；容忍值建议在 U6 任务开始前由验证集基线确定，不要看到 test 结果后再改。

在 U5.5 的报告目录输出 `u6_border_collie_improvement_plan.md`，把以上步骤转成下一阶段执行计划。可以更新项目进度清单中相关任务状态，但只允许做与本阶段直接相关的最小差异；不得大范围重写 README/TODO/PROGRESS。
