# U6.2：柯利牧羊犬 / 边境牧羊犬双候选提示实施任务

> **目标**：当 V2.1 对 `collie`（柯利牧羊犬）与 `border_collie`（边境牧羊犬）确实难以区分时，如实向用户展示两个候选，让用户自行判断。不要继续强迫模型为每张图片给出看似确定的单一细粒度品种。
>
> **本任务不训练、不下载数据、不重标标签、不访问 test split、不切换模型权重。** 当前正式模型仍为 V2.1（136 类），现有四类候选组（APBT / AmStaff / SBT / American Bulldog）必须保持现状。
>
> 项目路径：`E:\CatDogBreedNet`

## 0. 用户已确定的产品口径

用户已拒绝继续寻找外部数据集，选择直接采用双候选提示，但**只在系统确实不确定时显示**。

- `collie` → **柯利牧羊犬**
- `border_collie` → **边境牧羊犬**
- 两个标签仍是独立的模型类别，不合并标签，不改 checkpoint。
- 不因毛色为黑白就直接触发；现有自动毛色判断存在大量 `uncertain`，不可作为线上触发条件。
- 不将分数硬设为 50%/50%，也不伪造置信度。
- 保留原始 Top-1、Top-K 及原始 Softmax 输出；候选分数只展示为“候选组内相对得分”，明确声明它不是整体识别置信度、真实概率或准确率。
- 用户所选品种与模型预测分开显示，选择仅保留在前端组件状态，不写 SQLite，不覆盖历史预测。

候选组内相对得分计算：

`group_score_i = p_i / (p_collie + p_border_collie) * 100`

若原始两类概率接近，则归一化后自然接近 50/50；若不是，就必须如实显示实际比例。

### 2.1 建议的触发逻辑

只有同时满足以下条件才触发双候选提示：

1. 模型的原始 Top-1 为 `collie` 或 `border_collie`；
2. 两类完整 Softmax 概率之和达到最低质量阈值：`pair_mass = p_collie + p_border_collie >= MASS_THRESHOLD`；
3. 两类原始概率足够接近：`pair_margin = abs(p_collie - p_border_collie) <= MARGIN_THRESHOLD`。

必须使用完整 136 维 Softmax，不得从 Top-K 截断值推算。若 Top-1 是其他品种，不触发这组候选，即使这两个类别彼此接近，也不应暗示图片一定属于其中之一。

### 2.2 阈值扫描与选择要求

不要凭感觉硬编码阈值。新增验证脚本，对 `pair_mass` 与 `pair_margin` 做小范围网格扫描。每个阈值组合至少统计：

- 触发数 / validation 总数，触发率；
- Top-1 属于这两类的子集中，提示触发比例；
- 触发图片中真实标签属于 `{collie, border_collie}` 的比例；
- 真实 `collie` 和真实 `border_collie` 分别被提示的数量；
- 真实标签在组外的触发数量及标签列表；
- 每张触发图片的两类原始概率、pair_mass、pair_margin、Top-1 和触发原因。

阈值选择优先保持“只有难以区分时才提示”的语义，不以最大触发率为目标。由于 validation 中每类仅约 15–16 张，报告必须注明小分母限制。如果数据无法支撑稳定的阈值选择，应如实说明不确定性并采取保守阈值；不得宣称已经证明候选提示能提高分类准确率。

阈值冻结后记录独立版本号，例如 `val-YYYY-MM-DD-collie-pair-v1`。阈值版本必须和四类 bully 候选组版本区分开。

   - Top-1 为 `collie` 或 `border_collie` 时，使用本任务确定的双候选触发规则；

3. 若响应仍使用 `candidate_group` 字段，应增加明确的组标识（如 `group_id`）或依靠独立且明确的 `threshold_version` 区分两套策略；维持可选与向后兼容，不向 API 客户端暴露完整 136 维 `probabilities`。
4. 确保双候选的中文名、组内相对得分和说明文案正确。
5. 保持原始预测 Top-1、Top-K 顺序和分数不变。
6. 用户选择只在界面单独呈现，仅保存在组件状态，不写入数据库、不覆盖模型历史预测。
7. 关闭 `CATDOG_CANDIDATE_GROUP_ENABLED` 后，四类组和两类组提示都关闭，原始模型预测仍一致。
8. V1.1（37 类）回退时不具备两类组完整映射，双候选函数应安全返回 `None`，不得抛异常或干扰预测。
9. 不要把毛色启发式或人工复核备注用于运行时触发；它们只用于离线分析。

建议文案：
